# Google Chat 提醒

[English](README.md) | **繁體中文**

為 Google Chat（chat.google.com 與 Gmail 內的 Chat）加上訊息提醒功能。

## 安裝（不需要寫程式）
1. 前往[最新版本](https://github.com/marandy0905/chat-reminders/releases/latest)，下載 **chat-reminders.zip**。
2. 解壓縮，並把資料夾放在固定的位置（例如「文件」）。Chrome 會從該資料夾讀取擴充功能，所以之後請不要刪除或移動它。
3. 在 Chrome 網址列輸入 `chrome://extensions` 並開啟。
4. 開啟右上角的**開發人員模式**。
5. 點選**載入未封裝項目**，選擇剛剛解壓縮的資料夾。
6. 重新整理 Google Chat。如果系統詢問，請允許 Chrome 傳送通知。

小提示：點選 Chrome 工具列的拼圖圖示，將 **Chat Reminders** 釘選起來，圖示就會一直顯示。

## 使用方式
- **在訊息上設定：**將滑鼠移到訊息上，點選時鐘按鈕並選擇時間。通知會顯示訊息內容，點選通知即可回到該則訊息。
- **彈出視窗：**點選工具列圖示（或 Chat 內的時鐘按鈕），可查看即將到來的提醒，並進行延後、開啟或刪除。
- 通知上有 **延後 20 分鐘** 與 **標示為完成** 兩個按鈕；點選通知本身只會開啟聊天室。除非你按下**標示為完成**，否則提醒會維持「已逾期」狀態。
- **總覽：**彈出視窗中的**查看全部**會開啟總覽頁面，分為已逾期／今天／明天／之後／已完成，每則提醒都可延後（預設選項或自訂時間）、完成、開啟或刪除。
- **Chat 內的捷徑：**「New chat」按鈕旁的時鐘按鈕會開啟提醒面板（有逾期項目時顯示紅色與數量，否則為淡色）。快速鍵：**Alt+Shift+R**（可在 `chrome://extensions/shortcuts` 修改）。

## 更新
Chrome 無法自動更新這個擴充功能。它約每天檢查一次新版本，若有新版本，會顯示通知、在工具列圖示上顯示 **NEW** 標記，並在彈出視窗顯示提示。更新步驟：
1. 點選通知或提示，開啟最新版本頁面並下載 **chat-reminders.zip**。
2. 解壓縮並覆蓋原本的資料夾（取代檔案），或解壓縮到新資料夾後改載入該資料夾。
3. 開啟 `chrome://extensions`，點選 **Chat Reminders** 的重新載入圖示，然後重新整理 Chat。

## 備註
- 所有資料都儲存在 `chrome.storage.local`。唯一的網路請求是每日的更新檢查，只會讀取此專案公開的 `manifest.json`，不會傳送任何提醒資料。
- Google Chat 的 DOM 經過混淆。如果時鐘按鈕不再出現，請更新 `content.js` 開頭的 `SELECTORS`。
- 訊息的深層連結不會出現在 DOM 中，因此「開啟聊天室」會開啟設定提醒當下的聊天室／私訊網址。
